## 一、學生篇

### 加好友
LINE 搜尋 ID `@574gwhfk`，或掃老師提供的 QR Code → 加入好友。

### 怎麼問問題
直接打字傳訊息就好，例如：

```
二次函數的頂點怎麼求？
```

AI 教學助理**不會直接給答案**，會一步步引導你自己想出來：

```
你：二次函數 y = x² - 4x + 1 的頂點是多少？
助理：我們先想想看，頂點公式需要哪兩個係數？你能從這個式子找出 a 和 b 嗎？
你：a=1, b=-4
助理：沒錯！頂點的 x 座標是 -b/2a，你算算看是多少？
```

如果你試了兩次還是卡住，助理會示範完整步驟，再出一題類似題讓你自己練。

### 指令
| 輸入 | 作用 |
|------|------|
| `清除`、`clear`、`重置` | 清掉你的對話記錄，換新題目時建議先清除 |
| `幫助`、`help`、`?` | 顯示使用說明 |

### 能問什麼
- ✅ 數學、物理、化學、生物、歷史、地理、公民
- ❌ 感情、家庭問題、政治立場、閒聊 → 助理會建議你找師長或輔導室

### 小提醒
- 助理會記得你最近 **10 輪**對話，太久以前的會忘記
- 系統維護或重啟後記憶會清空，請重新描述題目
- 閒置一段時間後第一則訊息可能要等 **30 秒**才回（伺服器喚醒中），請耐心等候，不要重複傳

## 二、班級群組篇

### 老師：把助理加進班級群組
1. 群組右上角 ☰ → 邀請 → 搜尋「AI 教學助理」→ 邀請
2. 如果邀請不了，請管理員確認後台已開啟「允許加入群組」

### 學生：在群組裡怎麼問
助理在群組裡**不會回應一般聊天**（避免洗版），要用以下兩種方式之一：

| 方式 | 範例 |
|------|------|
| @ 助理 | `@AI 教學助理 光合作用的產物是什麼？` |
| 「問：」開頭 | `問：牛頓第二定律是什麼？` |

- 半形 `問:` 和全形 `問：` 都可以
- 每位同學的對話記憶是分開的，A 同學的問題不會被 B 同學看到上下文
- 在群組輸入 `@AI 教學助理 清除` 只會清除**你自己**的記錄

## 三、常見問題

| 狀況 | 怎麼辦 |
|------|--------|
| 傳了訊息很久沒回 | 伺服器可能在喚醒，等 30 秒；超過 1 分鐘請再傳一次 |
| 回覆「抱歉，我現在有點忙」 | AI 服務暫時忙碌，稍後重傳 |
| 群組裡打字沒反應 | 記得 @ 助理或用「問：」開頭 |
| 助理好像忘了前面講的 | 超過 10 輪或系統重啟過，請重新描述題目 |
| 回覆被分成好幾則 | 正常，內容太長時會自動分段 |
